# 紫微斗數 · 命盤解析

一個私人用的紫微斗數排盤與解讀網站。輸入生辰就能排出完整命盤，並用**完全白話、不含任何命理術語**的方式解讀個性、盲點、一輩子的流年運勢，以及任兩人的關係比對。

## 特色

- **免安裝、免建置** — 純瀏覽器就能跑，不需要 Node.js、不需要 `npm install`
- **免費、不需 API Key** — 解讀是預先寫好的，或由程式即時生成
- **零命理術語** — 報告裡不會出現「化忌」「三方四正」「擎羊」這類詞，全部翻成白話
- **一輩子的流年** — 從出生到 100 歲，每一年都算得出來
- **任兩人比對** — 用下拉選單自由配對
- **未成年自動放軟** — 未滿 16 歲會自動改用教養與引導的角度，寫給父母看
- **RWD** — 手機、平板、桌機都能用

## 怎麼跑

**方法一（最簡單）**：雙擊 `啟動.command`，會自動開啟伺服器和瀏覽器。

**方法二**：在專案資料夾執行

```bash
python3 serve.py
```

然後打開 http://localhost:8080

> ⚠️ 不能直接用 `file://` 開啟 `index.html`。這個專案用 ES modules，必須透過伺服器載入。
>
> ℹ️ 第一次開啟需要連網，會從 CDN 載入 Vue 和排盤引擎，之後瀏覽器會快取。

## 功能

| 分頁 | 內容 |
|---|---|
| 命盤總覽 | 十二宮、主星輔星、四化標記、大限 |
| 個性剖析 | 本性與天賦優勢 |
| 盲點與課題 | 致命盲點、性格弱點、人生功課 |
| 流年運勢 | 這十年 / 今年主軸 / 機會 / 要當心 / 一句話總結 |
| 兩人比對 | 合不合、爽點與雷點、各自要調整什麼 |

還可以新增、編輯、刪除人員，資料存在瀏覽器的 localStorage。

## 技術

- **Vue 3**（含 runtime compiler，由 CDN 載入，元件用 template 字串，不用建置步驟）
- **[iztro](https://github.com/SylarLong/iztro)** — 排盤引擎，負責所有星曜計算
- **localStorage** — 存人員資料與解讀
- **python3** — 只用來當靜態伺服器（`serve.py` 會關閉快取，避免載到舊檔案）

### 為什麼沒有建置流程

開發這個專案的機器上沒有 Node.js，所以刻意設計成不需要任何安裝或編譯。所有相依套件從 `esm.sh` 以 ES modules 載入。

## 專案結構

```
index.html            進入點
styles.css            樣式（含 RWD）
serve.py              本機靜態伺服器（關閉快取）
啟動.command          雙擊即可啟動
js/
  deps.js             外部相依（Vue、iztro）集中在這裡
  data.js             預設人員資料
  ziwei.js            iztro 封裝、排盤、時辰換算
  payload.js          把命盤嚼碎成解讀用的資料
  prompts.js          給 AI 的提示詞（選用功能）
  claude.js           Claude API 串接（選用功能）
  store.js            狀態管理與 localStorage
  markdown.js         極簡 Markdown 轉 HTML
  components.js       UI 元件
  app.js              主程式
  readings/           預先寫好的個性與盲點解讀
  interpret/          流年與比對的解讀引擎
    lexicon.js        術語→白話對照表
    yearly.js         流年解讀生成
    compare.js        兩人比對生成
docs/SPEC.md          完整規格與開發紀錄
```

## 關於準確性

排盤全部交給 iztro，已針對多個生辰驗證過四化、五行局、命身宮，以及**農曆跨年**（例如國曆 2 月初出生但在春節前，農曆年要退回前一年）等容易出錯的情況。

## 選用：接 Claude API

預設不需要。若想讓 AI 即時生成解讀，可在「設定」填入自己的 Anthropic API Key（存在瀏覽器本機，需自行付費），介面會多出「直接產生」按鈕。
